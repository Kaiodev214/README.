# 🍔 Sistema de Pedidos - Lanchonete

Sistema de pedidos para lanchonete feito em Python, direto no terminal.
O cliente faz o pedido, o sistema valida tudo e calcula o total e o troco
sem deixar o programa travar, mesmo se o cliente digitar errado.

## ✨ O que o projeto faz

- Pede e valida o nome do cliente
- Pede e valida o email
- Sistema de senha
- Cardápio de lanches e bebidas
- Soma automática dos pedidos
- Calcula o troco
- Validação completa: não aceita campo vazio, número negativo, letra onde era pra ser número ou caractere especial

## 🛠️ Tecnologias usadas

- Python
- `while True` para repetição e validação
- `try / except` para tratar erros de digitação
- loopings
- combinações de estruturas
- verificações com .startswith() e .endswitch()
- .....
